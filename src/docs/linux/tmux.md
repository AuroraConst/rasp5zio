### tmux
## Common commands
- `tmux ls` lists all tmux sessions
- `ctrl+b d` keyboard shortcut to detach from current tmux session
- `tmux attach -t <name>` attach to specific terminal session (see `tmux ls`)
- `tmus attach -s <name>` creates a new session
